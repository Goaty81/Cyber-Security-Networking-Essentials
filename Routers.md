<ins>Routers</ins>

Routers are the devices that allow us to connect to the internet, whether it be through wired or wireless connection. They serve two primary functions, they manage traffic in between networks by forwarding packets to the right destination and allowing multiple devices to connect to it.

The most common types of router used are LAN (local area network) and WAN (wide area network). LAN (local area network) is multiple connected devices restricted to a specific geographical location. WAN is distributed multiple geographical locations and can be spread out meaning it will need multiple LANs to create a WAN.

<ins> How does a router work?</ins>

Routers do exactly that, they route traffic to its destination. Think of it as a SATNAV, You punch in your destination and it will direct you the best way possible to it. The router does exactly that however with data! it does this by using a internal routing table which has a list of paths leading to various network destinations.

<ins>Specialised types of routers</ins>

Other than wireless and wired routers there and specialised routers that serve specfifc functions:

  - Core routers - These routers are normally used by large organisations that transmit a high volume of traffic within there network. These routers will normally operate within the network and have no communication with the external internet.
  - Edge routers - These will sit in between the external communications and the core routers. While core routers deal with internal traffic, these routers deal with the external communications within a organisation. These use a Boarder Gateway Protocol (BGP) to send and receive data from other networks.
  - Virtual routers - The other two router require a hardware device, This one does not. However it still has all the functions of the others, It will use Virtual Router Redundancy Protocol (VRRP) to establish primary and backup routers in case one fails.

<ins>What is an SSID</ins>

Service Set Identifier (SSID) is a technical term for naming a network. It enables uses to find there router to then connect to the internet.
